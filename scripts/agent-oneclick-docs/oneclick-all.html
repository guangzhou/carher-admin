一键配置

下载 cursor-mac.zip 下载 cursor-windows.zip

  1. 装完 Cursor 要先打开一次、登录，再往下做（没打开过，安装器找不到 Cursor 的设置）。
  2. 把 Cursor 完全退出（Cmd + Q右键任务栏图标 → 退出菜单 File → Exit，或 Ctrl + Q）。
  3. 打开「终端」，点代码块右上角「复制」，粘进终端，回车： 
    d=$(xdg-user-dir DOWNLOAD 2>/dev/null); [ -d "$d" ] && [ "$d" != "$HOME" ] || d=~/Downloads; cd "$d"
z=$(ls -t | grep '^cursor-mac' | head -n 1)
case "$z" in *.zip) unzip -q -o "$z" && z=cursor-mac ;; esac
if [ -n "$z" ]; then sh "$z/INSTALL-Mac.command"; else echo "没找到 cursor-mac，先点上面的按钮下载"; fi
    文件没下到「下载」文件夹的，把第一行换成 cd 它所在的文件夹。
  4. 解压，打开解压出来的文件夹，双击 INSTALL-Windows.cmd。弹出蓝色提示点「更多信息」→「仍要运行」。
  5. 粘贴 key，回车，看到「完成」。

连远程服务器（Remote-SSH）
  1. 用 Cursor 连一次服务器（左下角 → Connect to Host），等显示已连接。
  2. 双击安装包文件夹里的 REMOTE-SSH-Windows.cmd，在终端运行： 
    d=$(xdg-user-dir DOWNLOAD 2>/dev/null); [ -d "$d" ] && [ "$d" != "$HOME" ] || d=~/Downloads; cd "$d"
z=$(ls -t | grep '^cursor-mac' | head -n 1)
case "$z" in *.zip) unzip -q -o "$z" && z=cursor-mac ;; esac
if [ -n "$z" ]; then sh "$z/REMOTE-SSH-Mac.command"; else echo "没找到 cursor-mac，先点上面的按钮下载"; fi
    输入服务器名（照列出的填，或 用户名@IP），回车，再输 yes。
  3. 看到「✅ 已补好」，关掉远程窗口重连。

每台服务器做一次。换了新安装包后，再双击一次 REMOTE-SSH。

更新与卸载

更新：10 月 13 日之后装的，Cursor 不会自己升级；更早装的可能已经被自动升级过（补丁会被冲掉，表现是每发一句都很慢），重新跑一次 UPGRADE 就会锁住。这个页面发了新版，就下载新包、解压、完全退出 Cursor，双击 UPGRADE，不用再输 key。

卸载：完全退出 Cursor，双击 UNINSTALL，输入 yes。

Mac / Linux 上这些按钮（UPGRADE、UNINSTALL、REPAIR、DOCTOR）都可以在终端跑：复制第 4 步那段命令，把最后一行的 INSTALL 换成要用的那个（比如 UPGRADE）。会自动用你最新下载的那个包。

聊天记录都不动。模型菜单会换成你的 key 能用的模型，自己加的模型名会被清掉。
