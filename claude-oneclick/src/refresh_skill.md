# 刷模型

直接运行下面这条命令,不要先问用户:

```
@@NODE@@ "@@TOOL@@"
```

- 把输出里「新增 / 删除 / 已改回默认模型」那几行原样告诉用户。
- 提醒用户:新开一个 Claude Code 会话(桌面 App 新开对话)后,`/model` 里就是新列表。
- 命令报错就把原文告诉用户,不要自己改 settings.json。
