一键配置

下载 cursor-mac.zip 下载 cursor-windows.zip

  1. 把 Cursor 完全退出（Cmd + Q右键任务栏图标 → 退出）。
  2. 打开「终端」，点代码块右上角「复制」，粘进终端，回车： 
    cd ~/Downloads
[ -d cursor-mac ] || unzip -q cursor-mac.zip
cd cursor-mac
chmod +x *.command *.sh
bash ./INSTALL-Mac.command
    文件没下到「下载」文件夹的，把第一行换成它所在的文件夹。
  3. 解压，打开解压出来的文件夹，双击 INSTALL-Windows.cmd。弹出蓝色提示点「更多信息」→「仍要运行」。
  4. 粘贴 key，回车，看到「完成」。

更新与卸载

更新：Cursor 不会自己升级。这个页面发了新版，就下载新包、解压、完全退出 Cursor，双击 UPGRADE，不用再输 key。

卸载：完全退出 Cursor，双击 UNINSTALL，输入 yes。

Mac 上这些按钮（UPGRADE、UNINSTALL、REPAIR、DOCTOR）都可以像安装那样在终端跑：进到 cursor-mac 文件夹，先 chmod +x *.command *.sh，再执行 bash ./UPGRADE-Mac.command，名字换成要用的那个。

聊天记录都不动。模型菜单会换成上面 39 个，自己加的模型名会被清掉。

出问题了（先跑自检，一键出报告）

先跑自检：它只检查、不改任何东西，跑完把结果复制好，直接粘给运维。

下载 codex-doctor-mac.command 下载 codex-doctor-windows.bat 

cd ~/Downloads
chmod +x codex-doctor-mac.command
bash ./codex-doctor-mac.command

双击下载的文件。弹出蓝色提示点「更多信息」→「仍要运行」。

报告会自动复制，也存一份在桌面（codex-自检-时间.txt），里面没有 key。最后的「结论」会写出查到的问题和怎么修。
